User guide

Choose Help > OdenMap User Guide in the macOS app. The native help book supports offline reading and search in English and Chinese. Customizable shortcuts are in OdenMap > Settings > Keyboard Shortcuts.

Common questions

How do I join the iOS beta (iPhone and iPad)?

Use the public TestFlight link. Install Apple's TestFlight on the device, then accept the invitation. iOS 1.0 is in public beta and has not been released on the App Store.

Is OdenMap native?

Yes. The macOS edition is built with Swift, SwiftUI and AppKit, and supports Apple Silicon and Intel Macs running macOS 14 or later. The iPhone and iPad editions are native as well; the beta requires iOS 15 or later.

Is the iOS edition exactly the same as the macOS edition?

No, and we don't promise that. Both use the same node and document structure. Touch editing, resources, composite nodes and native export are implemented in the beta; some desktop interactions, file-format previews and window behaviour differ by device. Check the installed version for details.

Can a mind map be a node?

Supported map files can appear as resource previews inside another map, and supported resources can be attached above an ordinary text topic. Preview and paging depend on the format; a resource preview is not an editor for every nested map.

Where are documents saved?

OdenMap does not require an account and does not automatically upload maps or attachments to a developer-operated server. Documents are saved where you choose, including iCloud Drive or another sync folder; synchronization is handled by that provider.

Can offline HTML be edited or used for collaboration?

No. Offline HTML is a read-only map that pans, zooms and folds. It is not a web editor and does not offer online collaboration. Keep the .odenmap document to continue editing.

What is not promised

OdenMap does not provide its own cloud storage, online collaboration, OCR or cloud AI, and does not run a TeX compiler. Offline HTML is a read-only output. Resource previews depend on file format and size.

Feedback

Email odenmap_support@yeah.net. Include the system version, device model, a short description and steps to reproduce. Do not send private documents or personal details.
