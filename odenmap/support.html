使用与支持

使用手册

在 macOS 应用中选择“帮助”>“OdenMap 使用手册”。原生帮助书支持中英文离线阅读与搜索；可调整的快捷键位于“OdenMap”>“设置”>“快捷键”。

常见问题

如何加入 iOS 测试（iPhone 与 iPad）？

通过 TestFlight 公开链接加入。先在设备上安装 Apple 的 TestFlight，再接受邀请。iOS 1.0 目前处于公开测试，尚未上架 App Store。

OdenMap 是原生应用吗？

是。macOS 版使用 Swift、SwiftUI 与 AppKit 开发，支持运行 macOS 14 或更新系统的 Apple Silicon 与 Intel Mac。iPhone 与 iPad 版同样是原生应用，测试包要求 iOS 15 或更新。

iOS 版和 macOS 版完全一样吗？

不相同，也不应该这样承诺。两端使用同一套节点与文稿结构，触控编辑、资源与复合节点、原生导出在测试版中已经实现；部分桌面交互、文件格式预览与窗口行为随设备而不同。具体能力以当前版本为准。

思维导图也能成为节点吗？

受支持的导图文件可以作为资源预览放入另一张导图，也可以把受支持的资源嵌入普通文字主题上方。预览与翻页能力取决于文件格式；资源预览不等于在卡片内编辑任意层级的嵌套导图。

文稿保存在哪里？

OdenMap 不需要专属账户，不会自动把导图或附件上传到开发者运营的服务器。文稿保存到你选择的位置，也可以放入 iCloud Drive 等同步文件夹；同步由对应服务商处理。

离线 HTML 能编辑或协作吗？

不能。离线 HTML 是只读导图，可以平移、缩放和折叠，但不是网页版编辑器，也不提供在线协作。需要继续编辑时，保存 .odenmap 原稿。

没有承诺的能力

OdenMap 不提供自营云存储、在线协作、OCR 或云端 AI，也不运行 TeX 编译器。离线 HTML 是只读输出；资源预览受文件格式与大小限制。

反馈

请发邮件至 odenmap_support@yeah.net。请提供系统版本、设备型号、问题描述与复现步骤。请勿发送私人文稿或个人信息。
